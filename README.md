# SmartBin AI

**Smarter Waste Collection. Cleaner, Greener Campuses.**

SmartBin AI is a prototype designed to demonstrate how digital tools can support more efficient campus waste management.

## Features

* Waste-bin fill-level dashboard using sample data
* Visual charts for comparing bin status
* Collection-priority ranking
* Waste issue reporting form
* Rule-based waste-sorting assistant
* Environmental insights dashboard
* Light and dark themes

## Technology Stack

* Python
* Streamlit
* Pandas
* Plotly

## Current Limitations

This prototype uses sample bin data and predefined waste-sorting rules. It does not currently connect to live sensors, use a trained machine-learning model, or measure actual environmental savings.

## Run Locally

Install the dependencies:

`pip install -r requirements.txt`

Start the application:

`streamlit run app.py`

## Project Purpose

To demonstrate a practical, technology-assisted approach to campus waste monitoring, collection prioritization, and waste-segregation awareness.
